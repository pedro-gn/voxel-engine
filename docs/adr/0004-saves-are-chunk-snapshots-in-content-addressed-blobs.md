# Saves are chunk snapshots in content-addressed blobs

A save keeps every chunk's voxels (state bits included, light left out) in save regions of 256 × 256 blocks, full height, rather than the differences from the generated world. A delta would tie every save to the exact generator version, and in a multiplayer game every client and the server to it, and a load would have to generate the whole world first. The terrain document travels with the save for the editor and later regenerations, never to rebuild voxels.

A save is a package: one JSON manifest naming gzip blobs by the SHA-256 of their bytes. The store writes only the blobs it lacks and the manifest last, keeping a slot's two newest manifests, so a save that dies midway leaves the previous one loadable, and an unchanged region or section costs nothing. The sim copies only regions written since the slot's last save in this engine session. The same package maps onto object storage keyed by hash plus a database row per manifest. In a busy world random ticks touch every region within a few ticks, so there an autosave copies everything; it still stops the sim for about 20 ms at 512².

Resume is faithful, not bit-identical. Voxels, water volumes and flows, the sea account, falling blocks and fragments, the scheduler, units, orders, the work frontier and piles are saved exactly. Light is relit, water segments are rebuilt from the voxels and then given back their exact water, and navigation starts empty. Units drop their searches, paths, reservations and task claims and plan again from where they stand: a unit mid flat step stays put, one mid vertical step goes back to where the step began. Two loads of one save run identically; a loaded run is not identical to one that never saved.

Each section and the region format carry a version, and a save whose versions differ is refused with every mismatch named. The saved block table must be a prefix of the engine's: blocks can be appended, not reordered or removed. Commands not yet applied when the save is taken are not kept.
