# Sparse navigation and authoritative worker actions

Workers are opt-in and run inside the existing simulation worker. Navigation derives a sparse graph of supported body positions from authoritative voxels, retaining multiple floors in each column. A* is resumable, shares a bounded operation budget, and invalidates local region caches when relevant geometry changes. Exact straight region-boundary shortcuts retain ordinary edges and reconstruct every executable step; this is not a full HPA* abstraction.

The simulation remains the single writer. Dig/build actions validate tools, stock, target, reach and occupancy before conditional writes; inventory and drops commit with the voxel mutation. Flat movement simplifies up to 32 upcoming graph nodes through bounded visibility probes, requiring clear body volume and safe support throughout the shortcut. It reserves the swept body volume of the next tick; vertical transitions retain whole-action reservations. Waypoint transitions continue in the same simulation tick. This prevents overlaps and swaps but does not guarantee a solution to every multi-agent congestion problem. Local engineering is deliberately bounded and cannot plan arbitrary scaffolding or global construction dependencies.

Water and moving fragments are queried independently of cached geometry. Unsupported or pending structural support is handled conservatively. Existing normal/collapsible block rules and behavior with workers disabled are preserved. Full space-time planning, a global portal hierarchy and additional locomotion profiles require separate evidence from representative workloads.
